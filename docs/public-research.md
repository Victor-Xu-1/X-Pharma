# 公开来源检索与调研

X-Pharma v0.1.0区分两种结果。本地已治理情报来自获授权快照、统一暂存/发布及可重建投影，断网时仍可读取。公开来源调研只有人员明确执行后才调用官方接口；返回著录元数据、原文链接、时间和覆盖限制，不自动写入事实或标记verified。开放接口、公开网页与Apache-2.0都不授予第三方内容的完整再分发权。

## 人员工作流

本地检索默认包含已验证关联，可以取消勾选。按名称、来源别名或标识匹配，精确身份命中后最多扩展一层有当前已发布证据的关系。关联结果说明对象和关系，不把靶点名伪造成药物别名。筛选、排序、分页及分面使用同一命中集；URL、保存检索和监控保存相同模式，旧保存检索保持直接关键词语义。超过16个精确身份或1000条关系时不扩展，并提示缩小范围。

在情报、专利或交易页打开“公开来源调研”，检查关键词/范围，然后点击“查询公开来源”。展开面板、恢复页面、取消或返回前台不外发新关键词、不自动重试。不要发送患者、未公开项目或保密信息。各来源独立反馈可读取、当前范围未命中或暂不可用，网络失败不代表没有研究。本地覆盖来自当前组织已审核实体，不是全球覆盖量。

| 范围 | 提供者 | 数据边界 |
| --- | --- | --- |
| 药物、靶点 | ChEMBL | 名称/标识/来源别名、物种/类型或分子类型/最高阶段；最高阶段不是当前状态或获批用途 |
| 临床试验 | ClinicalTrials.gov | 注册元数据和原链接，不独立核实结果或药物效果 |
| 申办方、条件 | ClinicalTrials.gov | 当前试验页的来源名称，非全量机构/疾病库，不推断法律主体或获批用途 |
| 关键词专利 | Europe PMC PAT集合 | 历史著录，日期以原记录为准，不声称覆盖最新专利、家族、权利要求或法律状态 |
| 化合物专利引用 | PubChem PUG REST/PUG View | 药物名/CID解析后的交叉引用；化合物提及不证明保护范围、FTO或有效性 |
| 文献 | Europe PMC | 生命科学著录，不下载/再分发非开放许可全文 |
| 公司公告/交易线索 | Revolution Medicines、Kura Oncology官方RSS | 当前RSS页的标题/日期/链接，非全市场交易库，不填造金额/权益/确认合同；SEC自动访问受限时仅提供官方入口 |

综合调研并行查询药物、靶点、试验、历史专利和文献，其他范围单独执行。每个来源最多20条，页面默认10条。总命中数来自提供者，不用返回条数冒充总量；派生名称/RSS无可靠全量计数时返回null。PubChem只补读最前两条专利标题，其余保留标识；缺失字段不补造。

## 本地标准化与出处

已批准target profile中的gene_symbol进入同一别名权威，经原outbox投影检索。ClinicalTrials.gov适配器1.1.0形成条件/申办方的提供者范围名称实体；平台派生标识在通用身份解析中仍不受信，不能跨来源或组织自动合并。名称范围说明随公开档案返回。实体通过同一暂存事实获得provenance link；档案、证据覆盖和试验读取同一关系，结束关系/撤回事实不用于当前扩展。

来源名称的机构档案优先展示身份范围与关联登记试验，概览最多显示5项并提供临床分区入口。不用空管线图、零资产指标制造完整企业档案的印象；有独立公司身份的档案仍保留原专业概览。两种页面都不从登记申办方关系推断资产所有权。

注册干预顺序不能确认主药/联合用药。新适配器只记录唯一匹配的药物关联，不创建推断角色。历史官方角色行保留审计，但不参与角色展示/筛选，其他明确来源的治理角色不变。`clinical_links`统一登记关联和明确角色的计数/格局读取，不给一般关联赋予主药角色。历史角色须以明确来源重新治理，不能修改列表顺序或删除历史。

## 安全、升级及回退

`public_research/`只读、不写事实。HTTP要求人员会话和entities:read，拒绝Agent/API key即使有通配scope，不绕过MCP权益。POST受原CSRF及4KiB声明/实际流量上限保护，`request_body`复用账号与公开查询的同一限制实现，账号16KiB策略不变。

查询最长120字符，无控制字符，每次最多20条。出站仅固定官方HTTPS，拒绝凭据、自定义host/port、环境代理和重定向，不跟随上游任意分页URL。响应最多1MiB，HTTP超时/流式读取有界；每进程最多2个查询、3个来源并行，出站起始间隔至少250ms，无自动网络重试。RSS复用安全lxml解析器，禁止DTD/实体/外部解析/大树，不展示可执行HTML。

生产网络策略不会自动开放外网；在线调研须由目标运维配置受控HTTPS出口及供应商速率策略。失败时界面明确反馈，本地仍可查。不代表商业生产、全部数据许可、全球覆盖或科学结论验收。

两适配器1.1.0的指纹变化创建新运行，保留旧运行/快照/审核/溯源。升级前备份数据库、对象、Markdown及身份，从不可变快照经同一治理服务有界重处理/投影，不用SQL插入示例补页面。核对别名、名称、关系和出处。不新增表、产品版本或模型费用；应用回退不自动删除新增实体或历史审核。
