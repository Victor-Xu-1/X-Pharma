# X-Pharma 前端设计系统

## 目标与参考边界

最新要求：按已有预览图全面比对优化，不再以仅替换强调色作为完成标准。字号、控件、导航、检索行、档案身份与长标题、内部管理分区和响应式均对齐参考的清晰层级。正文16px、控件及结果14px、元信息12px；桌面主标题32px、移动26px；一般控件44px、主操作40px、导航48px。页面外间距32px，移动保持15px。仅调整呈现，不把AI示例、日期或误用的企业Logo当作真实事实。

档案身份头与图标共享一组规则，删除重复实现；公司登记来源概览拥有明确的资料面板，长记录标题完整换行。靶点指标和统计卡片按可用宽度自适应，不保留五列/三列产生的孤行。数据工厂流程图标48px、独立分区20px留白，投影状态按可用宽度自动分列。标准虚拟表格正文14px，紧凑正文12px及较小内边距，虚拟行高68/46不变，不能仅通过CSS增高导致虚拟滚动错位。

研究连续性的说明在唯一入口与按钮自然排版，检索页不再重复拥有说明；对象类型按钮可自然换行，保留实际计数、多选、公开调研和高级筛选。内部表单不再用全后代12px规则压缩数字、正文和标题；元信息仍按具体语义统一12px。没有独立AI参考的页面共用这些规格并逐页检查，不宣称已生成28张AI设计。

用户于 2026-10-03 将全站方向调整为 OpenAI 式的简洁设计与交互，取代原 Claude 风格。研究和内部工作台共用纯白画布、浅灰导航、黑白主操作和无衬线层级；减少重复标题、装饰性状态和嵌套卡片，先呈现当前任务，再按需展开复杂条件。专业查询、密集表格、档案、证据及内部治理能力和权限边界保留，不将产品变成没有真实业务能力的聊天演示页。

2026-10-05 用户要求先制作清爽的生物医药页面预览，再小幅美化现有前端。内置生图生成的检索页作为本轮共享视觉参考：保持白色画布、浅灰导航和黑白主操作，仅为链接、选中态、焦点和图表强调加入克制的青绿色，统一标题留白和控件层级。用户允许优先完成可运行预览；24个业务视图及登录/注册由同一主题实际渲染并分别记录，不把少数AI概念图冒称为全站实拍。概念图的示意记录、日期、来源措辞和重新绘制的标识不拥有科学事实或品牌权威，实际应用保留原图、真实响应和既有信息架构；不移植生成图中的虚构数据、企业Logo或额外业务字段。

参考边界为 [OpenAI 官方设计指南](https://openai.com/brand/) 与 [ChatGPT 公开产品入口](https://chatgpt.com/)；采用清晰层级和克制界面的方向，不复制商标或声称官方关系。当前网络下 ChatGPT 的浏览器参考页受访问验证阻断，没有绕过验证，也不宣称已完成登录后产品的逐像素比较。X-Pharma 的实际登录页已独立保存并审阅，产品验收仍须使用当前实现的真实浏览器截图与操作。

实现不复制参考产品的商标、图标、专有字体文件、源码或业务内容。X-Pharma 使用自己的名称和维护者提供的橙色品牌图像。所有标题和控件复用系统无衬线字体，标识和结构数据使用等宽字体；不依赖联网字体服务，缺少字体时按同一系统栈回退。相似的界面原则不等于整页像素一致。

## 中英文界面

商业运营的页签、表格、操作弹窗和生命周期记录消费同一英语优先语言状态；
原始客户名称、账期编号、币种、原因代码、法律依据和授权文本不翻译。
操作边界同步捕获单个意图，覆盖账户、争议、风险、导出、生命周期及
工作台导出策略；请求与权威重新读取完成前冻结冲突操作和页签。
当前权限拒绝隐藏失去读取授权的弹窗，不把缺失统计计数解释成零。
已返回额度以十进制字符串精确合计，派生展示不经过浮点或两位小数截断。
导出策略的字段按原领域目录渐进展开，默认保留同一字段 ID 和必需字段；
版本、格式、字段和授权文本在保存期间冻结，未提交草稿在面板切换时保留。
生命周期表单和记录按保留策略、保全、源资料、到期导出和审计拆分，父级
持有未提交草稿；页签与语言切换不丢失输入，刷新不覆盖脏草稿。新策略版本
须明确选择使用最新内容，保存后的基线只由匹配本次提交的权威读取确认。
常用整数小时和至少五分钟的时长可正常输入，区分停用策略与尚未配置。
清除、撤回、重新授权及解除保全显示精确目标并要求明确确认；失败后的
显式重试复用目标和原因，只有接口含幂等键的操作才复用操作键；解除保全
接口没有操作键，不宣称幂等重放。改变意图须取消并重新开始。目标变化或
当前读取未恢复时不提交旧操作；实际权限、保全和依赖门禁仍由服务端负责。
无阻断项仅表示本次读取未返回阻断项，保留期资格消费实测字段，不替代撤回
检查。删除重复英文眉题，商业页标题简化，窄屏保留完整文字和状态。
导出策略优先展示版本、上限和授权标注；字段组默认收起，已选字段计数与
未在当前目录定义的字段 ID 可见并原样保留。展开状态与草稿由同一父级
持有；服务端新版本不覆盖未提交编辑，明确采用最新策略前阻止保存。
刷新包含当前策略读取，不由语言切换触发读取或重放操作。
订阅权益、主体、计费、争议、导出、风险和生命周期的已返回记录详情按需
打开同一只读弹窗；使用共享模态焦点与背景隔离，Escape 返回原触发按钮，
中英文切换保留已打开详情。长内容不撑高表格行；固定弹窗标题保持关闭
入口可达。原始字段、原因、路径、摘要、签名和数值精度保持原样，返回
空列表、零和 false 不混同缺失。控制器拆分为读取、表单草稿、载荷构造和
生命周期操作模块，仍通过唯一同步操作边界与现有合同执行，旧内联实现
已退出。
相关单元、受控 Chrome 操作和中英文只读状态已有验证；真实账单、额度
调整、保全、清除与重新授权未用于布局验收。更多状态矩阵及最终部署仍
需继续验收，不代表全站获奖品质、科学数据覆盖或商业生产完成。

化学检索的父级控件、文本输入、结果、固定错误和保存反馈消费同一英语优先
语言状态；结构输入、阈值、展开项、请求缓存和原始名称/标识保持不变。
结果与画板异常边界各归属小模块，不保留旧内联呈现。精确质量与分子量保留返回
数值的可用精度，不固定截到四位小数；已捕获保存意图同步去重，离开页面后
不以迟到响应导航。画板自身状态和已识别第三方控件跟随同一语言状态，
可在原实例中往返切换；只保存受控界面文案的原始值，不修改 SVG 分子标注、
输入、输出值或可编辑来源文本。重复适配不产生无意义 DOM 写入，复用为新
动作的控件同步更新由适配器生成的无障碍名称，已有明确语义保持。
实际 Chrome 已验证画板切换及应用后保留原结构；待完成/拒绝/恢复的查询和
保存另由受控浏览器响应验证，不调用真实保存。查询失败不显示“尚未查询”，
移动搜索按钮与其他操作保持标准高度。局部检查不替代完整化学语义、全部
第三方菜单、全站状态或最终主线部署验收。

AI 审核的事实选择、来源对照、实体消歧、运行追踪和批次呈现使用同一语言
状态；原始名称、机制、引文、错误、路径和指纹不翻译。候选标题只采用
结构化载荷明确报告的研究对象，不从引文猜名称。事实与实体的备注按记录
分别保留，切换语言、选择或重新读取影响分析不丢弃草稿和显式规范实体选择。
审核控制器唯一拥有事实对照读取及决策意图；对照身份或状态不匹配、当前
读取失败、权限拒绝或正在刷新时不开放决策。提交期间冻结相关备注、记录
选择和工作区页签，迟到结果不能清除另一条记录的草稿。
运行记录保留已报告的零 Token 和成本精度，缺失与不完整上报另行标记。
审核布局及其窄屏规则随治理入口加载，不占研究首屏 CSS 预算；旧 payload
双列样式已退出，由唯一字段对照表承载。批次和投影维护的进一步验证边界
见下文；完整治理与全站品质仍需集成和部署验收，不能由局部检查替代。

批次选择、历史、预览、读取与操作分别由短模块承载；事实审核、批次发布
和投影请求使用同一工作区同步提交锁。当前读取失败或预览身份不匹配时
不能提交；401／403 隐藏失去授权的旧详情，普通失败明确保留只读历史。
相同预览意图的显式重试复用原幂等键，固定预览保持后台成员集合、哈希和
单次原子提交合同。候选行同时展示原始名称与定位，已替代圆角卡片堆叠。
投影计数的缺失、不完整和已观察到的零分别呈现；任何返回任务仍在运行
时不开放新请求。全局重建每次重新确认，复用唯一模态焦点与背景隔离；
提交期间不能关闭、改确认或借另一操作重复写入。刷新任务先重新核验
全局权限，受理反馈不冒充重建成功。以上写入状态已在隔离浏览器响应中
验证，实际维护权限仍由服务端 exact scope 和组织成员关系决定；未执行
真实全局重建或对现有待审事实进行批量发布，不用上述检查声明整个治理
工作台完成。

质量运营按读取、草稿、处置、覆盖、指标、历史和原始记录拆分。未提交的
责任人、备注、事件选择和筛选由当前工作区唯一拥有；切换治理页签不丢失
草稿，未进入质量页时不发起质量读取。处置捕获事件和版本，复用工作区
提交锁；当前问题、责任人或历史读取失败时不开放相应处置。权限拒绝隐藏
失去读取授权的缓存，暂时失败只显示明确标记的历史记录。关闭和豁免的

不适用和未报告适用性区分呈现；未知指标没有推测的百分比单位。趋势保留
已返回的未知指标，并可展开全部已读取快照。来源、快照和处置的完整原始
记录复用具名、可键盘滚动的披露区域，不以简洁为由丢弃返回字段。
这些状态已有定向单元与受控 Chrome 验证；真实接口的双语读取也已检查。
受控写入响应不等于对真实质量事件执行了处置，主线部署仍须另行验收。

`NewsView` 只持有原查询、草稿、分页、选择和保存状态；筛选、列、时间线、
统计、结果操作与详情由短模块呈现。切换不重读缓存、重放写入，也不关闭

专业查询入口与资讯页复用唯一日期校验。
标题、摘要、发布方、会议、未知类型和原始原因保持原文。
补充字段摘要之外可按需展开完整原始 JSON，零、false 与所有字段保留。

## 唯一样式权威

全站品质升级以专业研发工作流为中心，采用统一控件、明确的标题/档案身份层级、可读元信息、克制的状态反馈和快速响应；奖项评审是外部参考，不自授评分或宣称获奖。沿用 [Awwwards 评审维度](https://www.awwwards.com/about-evaluation/) 与 [Webby 评审维度](https://www.webbyawards.com/judging-criteria/) 检查设计、使用效率、内容、交互与整体体验，但不以装饰性动效替代真实数据和可访问性。

关闭的移动导航必须退出键盘与辅助技术范围；打开时背景不可交互，Escape 恢复入口焦点，切回桌面恢复正常导航。两入口共用“跳到主要内容”，检索页的 `/` 快捷键不能截获输入、IME 或模态窗口。档案页的工作域标题退为上下文，实际对象名称成为视觉主标题；来源身份与缺口提示仍完整保留。商业指标只在概览显示，操作页直接呈现当前任务。

两入口的受控导航标签使用 `sidebar-nav-label` 自然换行；英文工作流和组织动作
不能被侧栏的 nowrap/省略规则裁掉。最小控件高度、侧栏宽度、五个工作流和
收起后的隐藏规则不变；原始用户/组织名称仍由既有摘要与完整标题分别呈现。
内部企业/环境工具栏在唯一样式拥有者中回到正常文档流并允许换行，删除旧的
负外边距重叠和重复移动规则；不能遮住共享页头中的语言选择框。检查应包括
选择框的实际点击命中，而不只使用程序化 selectOption 验证翻译状态。

`useModalFocus` 唯一管理弹窗和移动导航的焦点、背景隔离与恢复。关闭的披露、隐藏或禁用的祖先不能成为初始/循环焦点；背景 sibling 分支以可嵌套的 `inert` 锁隔离，关闭后恢复原状态。移动导航仅以精确 ref 保留自身关闭遮罩可点击，不另写一套背景锁。Escape 在子控件处理后才交给最上层弹窗，尊重已消费事件、输入法组合和按住重复键；异步提交期间不退出确认框。来源和商业弹窗共用此规则，提交反馈在当前表单内，失败保留原因，成功后才关闭；新操作不继承上次错误。`FormStatus` 只呈现调用者的状态，不拥有请求、重试或业务判断。

两套侧栏的账户区由 `WorkspaceAccountNavigation` 唯一拥有，组织、退出、加载/失败反馈和折叠控制集中于导航底部。内部人员的姓名不再配上无真实探针支撑的“在线”绿点。页面保留一个明确主标题，移除内部重复的英文眉题及其无消费者元数据/样式。

数据工厂优先呈现数据源操作。流程能力说明、检索投影明细和空隔离目录由 `FactoryDetailsPanel` 原生渐进披露；读取失败、不可连接、失败/死信投递和待处置隔离案件会展开，摘要仍保留真实问题提示。`IngestionFlowOverview` 只说明已启用能力，不用五个成功勾号冒充一次实际执行；审核、发布是控制步骤，不标成已经完成。`SearchProjectionPanel` 明确区分可连接、投递失败、读取失败和上次缓存，重试复用原查询，不把失败面板隐藏掉。`QuarantineCasesPanel` 保留完整台账、只读/处置入口及有名称的键盘滚动区域，不因布局精简而改变权限、隔离状态机或操作请求。

数据工厂的来源、资产、运行记录和健康说明使用同一双语状态；来源名称、路径、模型标识、威胁签名、诊断、科学正文和未知代码保持原文。未观测或加载中的投影不能显示成可连接，当前权限拒绝隐藏缓存集群、版本和隔离事实，详情同时核对所请求标识。状态汇总合并来源与就绪数量，模型仅标明配置状态；常用来源先呈现操作和同步进度，治理字段渐进展开，投影异常提供前置定位入口。原生披露保留用户展开状态，不因错误恢复或语言变化自动收起。

`useFactoryOperation` 统一当前控制层的同步锁、挂载生命周期和结构化界面反馈，不增加请求或重试链路；迟到响应不能关闭其他界面，原始服务错误不按词典猜测翻译。重放与取消共用 `FactoryReasonDialog` 的原因输入和焦点控制，切换语言保留原始草稿、恢复阶段及幂等意图。数据源编辑由连接、治理、自动化三个呈现模块和单一模型组成，提交期间锁定完整表单；未修改的授权时间戳保留原始秒数和小数精度，不因分钟级输入而改写。分页在表格滚动区外独立重排，不能继承宽表的最小宽度而撑宽窄屏。

隔离台账在窄屏使用同一组行节点纵向呈现，文件名与主要操作相邻，其余字段保留可见名称。桌面仍为原表格，语义表头供辅助技术读取；不让待处置事件的操作藏到横向滚动区域末尾，也不使用强制点击证明按钮可用。

`SecondaryFilters` 只拥有渐进披露呈现，不读写查询、URL、缓存或权限。新闻的语言/会议/日期及流行病学的人群/口径/年龄/性别/日期默认收起，已有条件会显式展开并计数；控件关闭后仍保持挂载，草稿由原领域状态拥有。管线、临床、专利、交易和监管沿用各自已存在的高级条件与当前查询合同。清除、取消、保存、预览、档案返回、排序、分析和受控导出不被删除。

研发导航收束为情报检索、研发数据、竞争情报、研究动态、我的研究五个工作流。结构/证据属于检索，管线/临床/监管/疾病负担属于研发，专利/交易属于竞争，对比/监控/专题属于个人研究；页面内最多四项分类可自然换行，新闻单页和档案不叠加分类栏。账号/组织/退出仍固定底部。`lib/workspace/researchNavigation.ts` 唯一拥有分类和所属关系，`WorkspaceNavigation` 与 `ResearchViewNavigation` 只呈现该模型，`WorkspaceShell` 组装外壳和焦点，不复制查询状态。旧研究分组与其样式不保留。

临床的常用关键词、招募、分期、试验药物和靶点放在首层；设计、联用、关联项目与结果/发表按需展开，已有条件显示计数。管线的细分类与记录地区同样渐进披露。标签、查询/保存/清除及URL合同保留，不能为简洁删除有效筛选。

交易与资产首层只保留关键词、类型和状态。药品、靶点、适应症、参与方、角色和方向共用关联条件披露，其余交易条件继续复用 `SecondaryFilters`，已有草稿或恢复的 URL 条件自动展开并显示计数；同一机构的名称与规范 ID 只计为一个条件，数值零不是空值。`DealParticipantFilters` 只呈现控件，联想、规范实体选择、查询、验证、保存与 URL 仍由 `DealsView` 唯一拥有，不因折叠或语言切换清除草稿、选择、完整排序或复制请求逻辑。筛选、统计、结果动作和完整档案由短小呈现模块组成，不新增前端框架或查询权威。

交易界面采用同一英语优先语言状态，保存使用共享 `saveAndSubscribeSearch` 的结构化结果；监控失败保留已保存检索和原始原因，切换语言不重放写入。金额显示给定数值的完整精度及原始币种，不自行汇兑、不把小数舍入为零、不把未知值伪装为已披露；嵌套条款复用 `SourceMetadata` 的结构阅读和完整原始 JSON。存在机构/资产却没有结构化角色/交易阶段时仍显示已知原始对象，并明确标记缺失字段，不能删除整个记录。当前权限拒绝隐藏旧事实、筛选计数和档案数据，详情还核对所请求标识；未知/原型名称式代码在表格、筛选和已应用条件中保持原样。

交易权益表格的最小宽度与列宽由 `styles/regulatory.css` 唯一拥有，不在局部筛选样式重复覆盖、压缩权益范围正文。`ScrollableTableRegion` 保留命名及原生键盘横向滚动；机构检索分组、输入和候选列表使用独立名称，避免辅助技术或标签检索同时命中分组和输入。日期范围的两个输入保留明确间距，不引用不存在的设计变量。

机构候选查询失败与成功空结果明确区分，可重试且保留输入。所有金额筛选与每一项金额排序必须指定币种；非法金额、无效日历日期及接口不支持的枚举筛选值明确报错，保留草稿，不得静默删除条件后继续查询或保存。

交易高级日期与金额控件使用可收缩的三列桌面网格及单列窄屏网格，分组内部保留两端输入，不能让原生日期控件被挤到不可读。权益明细沿用具名键盘滚动区域，完整持有人、类型、地域、独占性和来源范围保留；窄屏完整金额独立成行，不能为缩短卡片截断、拆散或改变原始小数。

参与机构候选只在主动聚焦或编辑时显示，不因恢复已有自由文本条件而自动遮住相邻筛选。离开字段、Escape 或选择候选会关闭；上下方向键在候选间移动，选择后回到输入框。候选必须匹配当前防抖文本，不能展示上一个输入的过期候选；这些交互状态不清除查询、不触发提交，也不改变实体权限或后端检索语义。

机构候选使用全宽名称和可选的第二行外部标识，不继承关键词候选的图标列；无外部标识时不留下空行。长名称允许自然换行并保持完整，候选的可访问名称明确分隔机构名和标识，不截断科研实体名称。

专业结果摘要在移动端显式允许换行：数量与单位先呈现，页位置与查询时间独立成行；不让时间挤压单位，不删除或截断日期。该规则由既有专业结果工具栏的响应式样式拥有，七个专业查询域共用，不建立页面级重复摘要。

监管与安全首层仅保留关键词、监管机构和辖区，认定、标签、安全信号与日期等完整条件复用 `SecondaryFilters`，已有条件自动展开；切换语言只重绘本项目控件，不提交草稿、不重放保存、不同步改写原始记录。查询与保存状态仍由 `RegulatoryView` 唯一拥有，筛选、对比、详情和统计分别使用短小呈现模块；默认排序和显示方式不是可清除条件。保存复用 `saveAndSubscribeSearch` 的结构化结果，监控失败保留已保存检索和原始错误，不重复写入。

监管和研究动态的补充信息共用 `SourceMetadata`：紧凑的结构化阅读与完整原始 JSON 共存，零值、布尔值、嵌套对象和未知字段不删除。原始证据仍经过现有许可服务；当前读取返回 401/403 或响应资源标识不匹配时不展示旧证据，临时读取失败显示原始错误并明确标记上次可读取内容。监管详情和对比同样核对所请求标识，不能把缓存误当作当前授权，也不能把来源关联标识当成科学核验结论。未知状态码保持原样，已知控件和枚举由唯一语言目录翻译。

专利查询同样使用英语优先目录与唯一查询状态：首层是关键词、申请人和法律状态，关联实体及两组日期复用 `SecondaryFilters`。日期单独筛选和未提交草稿可清除，默认排序/显示方式不能算作有效条件；日期倒序在提交前明确阻止。列表选择、完整排序、草稿及保存中的名称在切换语言时保留。保存复用结构化 `saveAndSubscribeSearch` 结果，不因监控失败重复保存。当前权限错误使用实际传输层 `ApiError` 判断，拒绝后隐藏旧事实和筛选计数；详情还核对请求标识，临时刷新失败明确标记历史缓存。专利档案的公开文本逐条显示原始公开号、申请号、辖区和日期，申请人/发明人保留全量；已知状态只翻译既有词表，未知代码、来源标签、法律原文和研究内容均保持原样。档案标签沿用共享 `tab-bar` 的外观、触控及键盘语义，不新增第二套标签组件。

疾病负担页面同样由单一查询与草稿所有者组装筛选、结果、统计、同口径观测和保存反馈；英语是默认语言，原始方法、机构、人群名称与单位不改写。清除只针对实际草稿条件，不把默认排序或显示方式当作条件。当前读取权限失效后不展示缓存结果及其分面数量。趋势必须对应所请求的锚点与疾病，并逐项核对指标、地区、单位、人群、年龄、性别、发布机构和方法学；不能把不同来源的估计拼成同口径趋势。

趋势图响应式重排，完整数据仍由命名、可键盘滚动的原表格呈现；轴上可分行的观察期不改写原始提示与表格日期。估计值和提示复用有限数值格式化，不把小于千分位的有效数值四舍五入成零，不把缺失值补成零。提示直接创建文本节点、限制在图框内并按需折行，不解析来源字符串中的 HTML；接口已声明的截断状态必须明确呈现，不能假定完整曲线或未提供的置信水平。

审核的规范化差异和历史事实差异复用 `ScrollableTableRegion`：区域名称说明比较双方，键盘可以聚焦并横向滚动，完整字段、零值、布尔值和来源对照不因窄屏而删除。没有差异时不增加无意义的焦点停靠；不另写滚动或审核请求链路。

专业结果的 `as_of` 是服务端生成的本次查询时间，不是全部来源已更新至该时刻；`QueryResultSummary` 统一呈现查询时间和真实页位置，空页不显示0-0。`EmptyQueryResult` 将空组织/无可见发布数据与筛选零命中分开，零命中不能推断没有相关科学研究。错误与权限失败仍由原查询边界单独处理，不能变成空数据。

环境页面沿用同一主题和查询边界，明确区分网关包版本、主机检测时间、安装计划和已执行结果；未连接、过期或损坏报告不显示为健康，计划生成不显示为安装成功。公开版本号由 `pyproject.toml` 权威元数据同步，展示添加 `v` 前缀，不由CSS改写大小写；每个并线PR的自动进位规则见 CONTRIBUTING。

环境正文、页签、安装说明、探针状态与平台证据标题复用唯一语言状态，默认
英语；只翻译完整固定的本项目说明，未知诊断、路径、命令、原始报告、版本、
费用、审计标识和来源正文保留。`useEnvironmentInstallation` 唯一拥有草稿、
计划与请求状态，切换语言或页签不重置；请求期间锁定范围/离线选择和刷新，
同步锁阻止同一意图重复生成。未提供的范围或不支持的离线组合不能生成计划，
不自动改选或联网。网页始终只生成计划，主机执行仍须明确 CLI 授权。
探针只复用既有就绪判定；缺少实际观测不能显示符合要求。无探针时用明确空
状态，不铺宽空表；探针表将版本/身份等实测值自然换行，宽屏状态列保持可见，
窄屏仍保留命名、可键盘滚动的四列。平台计数由一个小型纯呈现模块校验，
缺失、畸形或不安全数值显示“未观测”而不是 0；真实零保留，不推断部署健康。

虚拟结果表按自身容器宽度处理固定列：宽于640px时保留选择栏与首列固定，较窄时只固定选择栏，让名称、类型、标识和操作在同一横向滚动区自然移动。不能用覆盖整屏的固定名称列遮挡预览/档案操作，也不靠 force click 或隐藏操作绕过。语义表格、排序、列偏好、行高、有限虚拟窗口及表头纵向固定保留；原真实浏览器列位移门禁按该规则验证全部列，不放宽像素或资源预算。

结构画板的操作与展开菜单使用各自独立的点击区域，移动工具栏换行而不遮住主操作；化学元素的标准颜色保留其科学语义。旧分组导航已没有消费者，相应 23 个样式选择器已删除，不保留另一套导航主题。

监控页面由提醒、主题、已保存检索三个独立呈现模块组成，查询、缓存、编辑及路由仍由原视图拥有。`useMonitoringOperations` 唯一管理重放读取、同步锁及页面生命周期：主题与提醒必须读取自己的固定版本，普通已保存检索必须重新读取当前授权和当前条件，不能用目录缓存替代。读取中保留明确状态和禁用入口；连续选择不同记录时只有最后一次意图可以导航或显示错误，同一记录重复提交不取代原意图；离开标签或页面后迟到响应不能导航，失败不能悄悄改用旧条件。创建主题时重新核对所选检索仍在当前可订阅目录中，不把已移除的选择改成另一个检索。

监控窄屏使用同一组表格节点纵向排版，字段标签保留、主要操作与记录名称相邻且在视口内可见；操作附短文字，不要求先横向滚动。桌面保持原表格，移动与桌面不复制另一套查询或按钮。名称、完整条件、权限范围、版本和日期不因收束布局而丢失；语义表头仍保留供辅助技术读取。

列表导出收束为标题操作区中的原生渐进披露，默认不请求策略、不展开字段。`CollectionExport` 只呈现，`useCollectionExport` 唯一管理读取、选择与请求，展示词汇模块不授予权限。策略读取/刷新与失败期间关闭提交能力；未配置、未开放、空列表、整份列表超限及列表版本未核对分别说明。列表导出遵循记录编号、类型和名称三项必需字段，不能套用专业查询导出的 ID-only 规则，也不能悄悄截断列表。相同失败意图显式重试保留幂等键，列表版本、格式、字段或策略指纹改变后创建新意图；成功生成后下一次导出是新操作。切换输入清除旧操作反馈，离开记录后不触发迟到下载。后台许可、配额、审计及文件编码仍由原有服务负责；无许可或计费状态的浏览器夹具不作为实际授权导出证明。

企业管理的七个面板复用英语优先的固定文案目录；组织、人员、用户组、模型名称、ID、供应商地址和服务端原始业务值保持原样。`useEnterpriseOperationBoundary` 唯一拥有同步提交锁、活动读取对账和页面生命周期，邀请、人员、组、访问、API 密钥与模型操作不能并发绕过；当前记录读取失败/刷新中或目标版本改变时阻止旧意图提交，保留草稿并要求重新核对。提交期间禁用冲突标签、关闭和表单输入，错误显示在当前可见表单中。一次性密钥和邀请码只属于当前可见弹窗，不保留在通用 Mutation 历史；离开页面或当前权限拒绝后不可继续显示。

`useAccountInvitations` 在工作台内保留邮箱和有效期草稿，换标签/语言不清空；呈现和一次性代码弹窗各自独立，原有两个邀请 Mutation 已退出。邀请等待/失败反馈复用 `FormStatus`，未知服务器失败继续使用安全固定提示，不暴露私有数据库/供应商信息。审计查询不再借另一组筛选的结果做占位；新条件读取期间保留筛选控件并隐藏旧结果，当前失败独立重试，清除同时移除已执行条件和未提交动作。返回同一仍有效的查询可以使用其匹配缓存，不强制重复请求；动作、操作者和请求 ID 不因语言变化改写。模型列表与配置弹窗分别归属小模块，既有预设只说明填入现有配置，不宣称当前供应商可用，也不因界面审查自动调用付费模型。

## 验证范围与通过标准

账号头像由 `UserAvatar` 统一呈现，图片失败状态只属于当前地址；显式换地址或清空后重试会建立新的图片尝试，不让一次失败锁住以后所有预览，也不自动循环重试。缺图时取完整姓名首字素，保留扩展汉字和组合音标；不改写实际姓名。已保存头像与编辑预览复用同一组件，原有无 referrer 图片策略与资料保存、身份隔离保持不变。

登录入口的加入组织确认复选框与说明同排、顶部对齐；长说明自然换行，整段文字仍是可点击标签。键盘 Space 可以勾选或取消，缺少凭据与邀请码时确认按钮仍不可提交；只统一控件的阅读布局，不改变邀请码、身份验证或跨组织授权规则。

环境管理的安装范围 `fieldset` 和网格子项显式允许收缩，不能让浏览器默认的 `min-content` 把窄屏页面撑宽；安装说明、前提和离线选择自然换行，不继承表格摘要的省略样式，刷新按钮的动作文字保持一行。平台服务、SLO、发布证据与审计表统一复用 `ScrollableTableRegion`，有明确区域名称和原生键盘横向滚动入口；不截断请求 ID 或删除长字段，也不新增一套表格滚动逻辑。布局和阅读验证只读取状态，不生成安装计划、不安装、不下载、不重启或修改其他项目。

监控目录中的业务说明以原生 `details/summary` 渐进展开，初始不铺开长段文字；所有者和共享只读人员都能用键盘、触屏或鼠标读取完整说明。展开正文保留换行并自然折行，不继承摘要的省略样式；没有说明时不显示空入口。只用 React 文本节点，不引入 HTML 解析，也不触发编辑、共享或其他服务器写入。

跨档案的返回上下文不是无限历史日志：统一 URL 合同以非递归方式校验同一研究工作台内的路径，仍限制输入和输出为 4096 字符、解析工作为最多 16 个帧；输出最多保留最近两级与起始研究。连续查看靶点、药物、试验或其他档案时，不能为了截短地址丢掉起始检索的筛选、排序和分页，也不能把外站、内部工作台、重复参数或非法标识当作起点。更早的实际访问仍由浏览器历史拥有，工作台按钮仅表示这个有界上下文；不新增菜单或第二套导航状态。

验证按当前差异选择：共享焦点/菜单/标签页、来源与商业弹窗、完整关联列表及靶点/知识重排分别检查自身行为和直接消费者；不改业务 API 或权限协议。实际浏览器还需检查展开态、隐藏背景、移动导航恢复和可滚动内容，而非只截默认首屏。局部通过不宣称所有模块/状态已完成，也不等于完整 WCAG 认证或外部奖项评审。
