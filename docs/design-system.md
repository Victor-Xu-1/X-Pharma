# X-Pharma 前端设计系统

## 目标与参考边界

最新要求：按已有预览图全面比对优化，不再以仅替换强调色作为完成标准。字号、控件、导航、检索行、档案身份与长标题、内部管理分区和响应式均对齐参考的清晰层级。正文16px、控件及结果14px、元信息12px；桌面主标题32px、移动26px；一般控件44px、主操作40px、导航48px。页面外间距32px，移动保持15px。仅调整呈现，不把AI示例、日期或误用的企业Logo当作真实事实。

档案身份头与图标共享一组规则，删除重复实现；公司登记来源概览拥有明确的资料面板，长记录标题完整换行。靶点指标和统计卡片按可用宽度自适应，不保留五列/三列产生的孤行。数据工厂流程图标48px、独立分区20px留白，投影状态按可用宽度自动分列。标准虚拟表格正文14px，紧凑正文12px及较小内边距，虚拟行高68/46不变，不能仅通过CSS增高导致虚拟滚动错位。

研究连续性的说明在唯一入口与按钮自然排版，检索页不再重复拥有说明；对象类型按钮可自然换行，保留实际计数、多选、公开调研和高级筛选。内部表单不再用全后代12px规则压缩数字、正文和标题；元信息仍按具体语义统一12px。没有独立AI参考的页面共用这些规格并逐页检查，不宣称已生成28张AI设计。

用户于 2026-10-03 将全站方向调整为 OpenAI 式的简洁设计与交互，取代原 Claude 风格。研究和内部工作台共用纯白画布、浅灰导航、黑白主操作和无衬线层级；减少重复标题、装饰性状态和嵌套卡片，先呈现当前任务，再按需展开复杂条件。专业查询、密集表格、档案、证据及内部治理能力和权限边界保留，不将产品变成没有真实业务能力的聊天演示页。

2026-10-05 用户要求先制作清爽的生物医药页面预览，再小幅美化现有前端。内置生图生成的检索页作为本轮共享视觉参考：保持白色画布、浅灰导航和黑白主操作，仅为链接、选中态、焦点和图表强调加入克制的青绿色，统一标题留白和控件层级。用户允许优先完成可运行预览；24个业务视图及登录/注册由同一主题实际渲染并分别记录，不把少数AI概念图冒称为全站实拍。概念图的示意记录、日期、来源措辞和重新绘制的标识不拥有科学事实或品牌权威，实际应用保留原图、真实响应和既有信息架构；不移植生成图中的虚构数据、企业Logo或额外业务字段。

参考边界为 [OpenAI 官方设计指南](https://openai.com/brand/) 与 [ChatGPT 公开产品入口](https://chatgpt.com/)；采用清晰层级和克制界面的方向，不复制商标或声称官方关系。当前网络下 ChatGPT 的浏览器参考页受访问验证阻断，没有绕过验证，也不宣称已完成登录后产品的逐像素比较。X-Pharma 的实际登录页已独立保存并审阅，产品验收仍须使用当前实现的真实浏览器截图与操作。

实现不复制参考产品的商标、图标、专有字体文件、源码或业务内容。X-Pharma 使用自己的名称和维护者提供的橙色品牌图像。所有标题和控件复用系统无衬线字体，标识和结构数据使用等宽字体；不依赖联网字体服务，缺少字体时按同一系统栈回退。相似的界面原则不等于整页像素一致。

## 品牌素材

产品和 GitHub 仓库名称统一为 **X-Pharma**（大小写固定）。Python 发行包规范化标识 `x-pharma`、内部模块和持久化标识不是对外软件名，不作破坏性迁移。

维护者于 2026-09-30 提供的透明 RGBA 原图保存在 `apps/web/brand/X-Pharma.png`，1254×1254，SHA-256 为 `1099f1a295921cc9e229995cd84aced5a2e1022e223bf6140f65d585f7b7d591`。不重绘、不裁切、不改色、不加背景；只通过锁定的 Pillow 生成等比缩放版本。两套工作台和登录页仅通过 `BrandMark` 使用同一个 128 px 图像，避免品牌入口分叉。

浏览器使用 16/32 px PNG、含 16/32/48/64 px 的 ICO 和 180 px Apple Touch 图标。三个 HTML 入口的声明由契约测试校验；Vite 产出带内容指纹的文件名，HTML 不缓存，从而在品牌更新后载入新图标。无需外部图片或字体服务。

默认 `/favicon.ico` 和可选 Swagger/ReDoc 文档同样使用这套构建产物，不另存第二份图标。默认图标地址强制重新验证，缺失、歧义或符号链接不提供任意文件；文档开关仍默认关闭，不因品牌调整开放 API 文档。

更新素材时替换原图、审查并更新生成器内的原图摘要，然后运行 `uv run python scripts/generate_brand_assets.py`；运行 `uv run python scripts/generate_brand_assets.py --check` 只读验证派生物。派生 PNG/ICO 不手工编辑。品牌图像按维护者提供的项目标识使用；Apache-2.0 不授予商标权。

## 唯一样式权威

全站品质升级以专业研发工作流为中心，采用统一控件、明确的标题/档案身份层级、可读元信息、克制的状态反馈和快速响应；奖项评审是外部参考，不自授评分或宣称获奖。沿用 [Awwwards 评审维度](https://www.awwwards.com/about-evaluation/) 与 [Webby 评审维度](https://www.webbyawards.com/judging-criteria/) 检查设计、使用效率、内容、交互与整体体验，但不以装饰性动效替代真实数据和可访问性。

关闭的移动导航必须退出键盘与辅助技术范围；打开时背景不可交互，Escape 恢复入口焦点，切回桌面恢复正常导航。两入口共用“跳到主要内容”，检索页的 `/` 快捷键不能截获输入、IME 或模态窗口。档案页的工作域标题退为上下文，实际对象名称成为视觉主标题；来源身份与缺口提示仍完整保留。商业指标只在概览显示，操作页直接呈现当前任务。

`useModalFocus` 唯一管理弹窗和移动导航的焦点、背景隔离与恢复。关闭的披露、隐藏或禁用的祖先不能成为初始/循环焦点；背景 sibling 分支以可嵌套的 `inert` 锁隔离，关闭后恢复原状态。移动导航仅以精确 ref 保留自身关闭遮罩可点击，不另写一套背景锁。Escape 在子控件处理后才交给最上层弹窗，尊重已消费事件、输入法组合和按住重复键；异步提交期间不退出确认框。来源和商业弹窗共用此规则，提交反馈在当前表单内，失败保留原因，成功后才关闭；新操作不继承上次错误。`FormStatus` 只呈现调用者的状态，不拥有请求、重试或业务判断。

保存检索的调用页面必须显式传递当前保存错误；失败在当前弹窗中唯一呈现，不能藏在已隔离的背景页面。关闭后保留可读反馈，下一次打开重置旧请求状态；不自动重试保存或订阅。保存期间名称、共享和订阅选项锁定，研究资料及来源重放/取消/隔离的原因与阶段同样锁定，恢复编辑后原输入和操作幂等键仍由各自业务状态持有。隔离复扫的“已提交”与随后案件刷新分别说明，不能改写成安全扫描完成。

知识正文由 `KnowledgeDocument` 唯一呈现为安全的 CommonMark/GFM 结构；不执行原始 HTML，不自动读取外部图像，仅允许 HTTP(S) 与本页引用链接。引用、返回锚点与辅助说明按实例隔离，完整公开 Markdown 保留在可键盘核对的只读原文区。临床要点优先显示登记编号、试验状态、分期、人数与日期精度，补充字段按需展开；不能把登记完成解释为药物获批。`KnowledgeStructuredValue` 共用于正文与版本差异，零、false、未知字段和完整原始值保留，不自行补齐事实或来源。原先的纯文本正文/整段JSON默认显示与无消费者样式已删除。

`KnowledgeCatalog` 只拥有目录的渐进披露和隐藏焦点恢复，知识页仍唯一拥有查询、分页、选中专题、版本与 URL。窄屏选中专题后默认先呈现正文，目录可随时展开，检索草稿与全部筛选保留；选择专题时焦点进入完整标题，桌面目录持续可见。临床字段复用既有登记词表；日期仅按记录的日/月/年精度表达，不经本地时区改写，缺失精度、非法日期、非午夜或非 UTC 原值保持字面形式。未知类型/临床代码与完整原文保持可核对，不推断获批、疗效或新事实。

八域导出入口按需打开同一个原生披露；关闭时不读取策略或播报后台策略错误。正在读取、读取失败/重试、未配置、策略禁用、缺少必需授权字段、记录上限为零和查询零结果分别说明，不把连接失败或零命中归咎账号许可。读取失败/刷新期间不能用旧缓存发起新导出，提交期间原设置锁定并保留当前反馈；重试策略读取不执行导出。字段、查询、许可、幂等和文件编码仍由既有领域合同与服务端权威控制，不在研究入口授予权限。

商业、治理（含实体消歧范围）、结构输入与知识视图复用 `ResearchTabList` 的方向键、Home/End、单一 Tab 停靠点和关联面板，不保留鼠标专用标签页。原生筛选、排序、列设置和导出弹出菜单由 `useDismissibleDetails` 统一处理 Escape、外部点击/焦点及返回入口，不清除草稿或已选条件；普通高级条件披露不自动关闭，导出提交期间保留原生展开与反馈。临床/专利表格的关联实体不再静默取前三项：首项与明确的其余数量进入完整授权列表，档案中的明确角色完整呈现，不推断关系优先级。靶点筛选由靶点样式拥有，自适应列与原控件尺寸取代固定三列最小宽度；知识覆盖网格将宽表格和版本列表约束在各自滚动区，不能撑宽移动页面。

展开在普通文档流中的筛选框，不能在 pointer-down 或同一次指针焦点转移时收起：布局移动会抢走目标控件的 pointer-up/click。共享退出规则等完整激活手势结束再关闭旧框；键盘离开仍立即处理，取消手势不留下挂起状态，程序触发的下载不隐藏提交反馈。此规则不依赖增加等待时间、禁止多个筛选值或改写已应用条件。

空列表使用共享 `EmptyState`，不得把提示放在宽表格的跨列单元格里，使移动端只能看到空白。内部管理表格通过 `ScrollableTableRegion` 命名、聚焦并支持键盘横向滚动；分组审核队列与普通队列共用按钮样式。环境与组织面板的布局分别由其局部样式拥有。证据/知识页的 `styles/knowledge.css` 由两个所属视图按需导入，同时拥有各自响应式规则，不再从初始全局样式或其他领域重复导入；设计契约仍包含这些按需样式。主线构建继续使用原 JS/CSS、视觉和性能预算，不放宽门禁。

- `styles/theme/tokens.css`：颜色、字体、字号、尺寸、圆角、阴影和状态语义。
- `styles/theme/foundation.css`：共享控件、导航、面板、表格、焦点和运动偏好。
- `styles/theme/typography.css`：密集信息与档案正文的可读性层级。
- `styles/theme/surfaces.css`：内部治理与专业业务表面的共享处理。
- `styles/theme/adapters.css`：结构编辑器、滚动容器及其他边界适配。
- `styles/*.css`：领域布局与响应式，不引入独立硬编码色值。
- `components/chartPalette.ts`：集中图表色盘；共享色值须与 CSS token 契约保持一致。

两个工作台通过同一 `mountApplication` 加载样式。禁止添加第二个主题开关、蓝色兼容链、页面级色盘或 `!important` 覆盖。新增视觉规则先复用既有 token；调整公共 token 时追踪全部消费组件。

颜色语义包括成功、警告、错误和中性信息，不将所有状态涂成同一种强调色。表格列可横向滚动，但页面本身不得溢出；移动导航保持焦点管理和关闭恢复。动态加载、空、错误、无权限、禁用和恢复动作遵循同一体系。

`chartPalette.ts`的轴线/网格与共享token一致，通用图表强调复用科研青绿色；分期刻度、缺失、失败与疗效分类保留既有独立语义，不为风格统一把警告或失败改成成功色。没有第二个主题、页面色盘、联网字体、装饰资产或新依赖。侧栏SVG的两个相同选择器合并，不保留重复声明；品牌源图和生成物未改。构建与AA对比度继续使用原门禁，不能因美化提高JS/CSS预算或像素容差。重复的结果类型栏和相应无消费者facet样式已删除，唯一对象类型栏保留总数与分类型计数，并通过原查询状态与行为回归。

注册复用登录页的白色画布、表单和账号入口导航；登录去除重复的英文/装饰眉题与锁形图标，账号入口、错误、成功、禁用和 OIDC 行为保留。邀请码管理仍复用企业表格、共享模态面板与唯一的模态焦点 hook；一次性邀请码关闭后清除，不引入另一套弹窗。

两套侧栏的账户区由 `WorkspaceAccountNavigation` 唯一拥有，组织、退出、加载/失败反馈和折叠控制集中于导航底部。内部人员的姓名不再配上无真实探针支撑的“在线”绿点。页面保留一个明确主标题，移除内部重复的英文眉题及其无消费者元数据/样式。

`SecondaryFilters` 只拥有渐进披露呈现，不读写查询、URL、缓存或权限。新闻的语言/会议/日期及流行病学的人群/口径/年龄/性别/日期默认收起，已有条件会显式展开并计数；控件关闭后仍保持挂载，草稿由原领域状态拥有。管线、临床、专利、交易和监管沿用各自已存在的高级条件与当前查询合同。清除、取消、保存、预览、档案返回、排序、分析和受控导出不被删除。

研发导航收束为情报检索、研发数据、竞争情报、研究动态、我的研究五个工作流。结构/证据属于检索，管线/临床/监管/疾病负担属于研发，专利/交易属于竞争，对比/监控/专题属于个人研究；页面内最多四项分类可自然换行，新闻单页和档案不叠加分类栏。账号/组织/退出仍固定底部。`lib/workspace/researchNavigation.ts` 唯一拥有分类和所属关系，`WorkspaceNavigation` 与 `ResearchViewNavigation` 只呈现该模型，`WorkspaceShell` 组装外壳和焦点，不复制查询状态。旧研究分组与其样式不保留。

临床的常用关键词、招募、分期、试验药物和靶点放在首层；设计、联用、关联项目与结果/发表按需展开，已有条件显示计数。管线的细分类与记录地区同样渐进披露。标签、查询/保存/清除及URL合同保留，不能为简洁删除有效筛选。

专业结果的 `as_of` 是服务端生成的本次查询时间，不是全部来源已更新至该时刻；`QueryResultSummary` 统一呈现查询时间和真实页位置，空页不显示0-0。`EmptyQueryResult` 将空组织/无可见发布数据与筛选零命中分开，零命中不能推断没有相关科学研究。错误与权限失败仍由原查询边界单独处理，不能变成空数据。

环境页面沿用同一主题和查询边界，明确区分网关包版本、主机检测时间、安装计划和已执行结果；未连接、过期或损坏报告不显示为健康，计划生成不显示为安装成功。公开版本号保持原始 `v0.1.0` 大小写，不由CSS改写。

结构画板的操作与展开菜单使用各自独立的点击区域，移动工具栏换行而不遮住主操作；化学元素的标准颜色保留其科学语义。旧分组导航已没有消费者，相应 23 个样式选择器已删除，不保留另一套导航主题。

## 验证范围与通过标准
