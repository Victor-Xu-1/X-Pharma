# X-Pharma 前端设计系统

## 目标与参考边界

按用户要求，全站贴合 Claude 默认浅色产品的风格：暖白纸面、浅米灰导航、炭黑文字和主操作、衬线标题、无衬线工具控件、细边框与轻阴影。保留专业情报平台的组合查询、密集表格、档案和内部治理能力，不把业务工作台替换成聊天演示页。

参考为 [Claude 官方产品页面](https://claude.com/product/overview) 的公开可见界面。2026-09-30 的独立 Chrome 会话确认了 `#faf9f5` 纸面、`#141413` 正文、衬线展示标题、无衬线控件及克制的圆角；登录应用在当前网络下跳转到地区不可用页面。因此不宣称已完成登录后实时应用的逐像素比较。

实现不复制商标、图标、专有字体文件、源码或业务内容。X-Pharma 保留自有名称和药物研究图标。字体使用本机已有的 Georgia/Noto Serif 与系统无衬线字体，不需联网字体服务；缺少对应字体时按声明的系统栈回退。专有字体和不同业务布局意味着风格相似不等于整个页面的像素一致。

## 唯一样式权威

- `styles/theme/tokens.css`：颜色、字体、字号、尺寸、圆角、阴影和状态语义。
- `styles/theme/foundation.css`：共享控件、导航、面板、表格、焦点和运动偏好。
- `styles/theme/typography.css`：密集信息与档案正文的可读性层级。
- `styles/theme/surfaces.css`：内部治理与专业业务表面的共享处理。
- `styles/theme/adapters.css`：结构编辑器、滚动容器及其他边界适配。
- `styles/*.css`：领域布局与响应式，不引入独立硬编码色值。
- `components/chartPalette.ts`：集中图表色盘；共享色值须与 CSS token 契约保持一致。

两个工作台通过同一 `mountApplication` 加载样式。禁止添加第二个主题开关、蓝色兼容链、页面级色盘或 `!important` 覆盖。新增视觉规则先复用既有 token；调整公共 token 时追踪全部消费组件。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 纸面 / 导航 | `#faf9f5` / `#f0eee6` |
| 正文 / 强调正文 | `#3d3d3a` / `#141413` |
| 装饰强调 / 可读强调文字 | `#d97757` / `#9c4a2b` |
| 主操作 | 炭黑背景、暖白文字；不使用浅陶土色承载小号白字 |
| 控件 / 面板 | 8 px / 12 px 圆角；登录面板 16 px |
| 字体 | 衬线页标题；无衬线表单、导航、表格；等宽标识与结构数据 |
| 密度 | 主体 14 px、正文 13 px、元信息至少 12 px；不为装饰增加表格行高 |
| 焦点 | 高对比陶土色轮廓；键盘可见，不能只通过颜色表示状态 |

颜色语义包括成功、警告、错误和中性信息，不将所有状态涂成同一种强调色。表格列可横向滚动，但页面本身不得溢出；移动导航保持焦点管理和关闭恢复。动态加载、空、错误、无权限、禁用和恢复动作遵循同一体系。

结构画板的操作与展开菜单使用各自独立的点击区域，移动工具栏换行而不遮住主操作；化学元素的标准颜色保留其科学语义。旧分组导航已没有消费者，相应 23 个样式选择器已删除，不保留另一套导航主题。

## 验证范围与通过标准

本次变更影响全局样式、图表和登录布局，不改业务 API 或权限协议。

| 风险 | 验证 | 通过标准 |
| --- | --- | --- |
| 全局主题分叉 / 颜色遗漏 | `DesignSystemContract.test.ts` | 两入口共用；领域无硬编码色盘；token 完整；文本对比度 AA |
| 业务交互、状态和导航退化 | `corepack pnpm test` | 全部前端状态与组件回归通过 |
| 类型 / 格式 / 首屏膨胀 | `corepack pnpm check`、`corepack pnpm build` | 类型与格式无错误；原构建预算不放宽 |
| 页面、焦点、无障碍、重排 | 真实 Google Chrome / Playwright | 1440×900、1920×1080、1024×768、390×844；登录、全域导航、结果、弹窗及刷新正确；WCAG A/AA 与页面无溢出 |
| 有意视觉变化 | 原项目浏览器基线更新流程 | 人工审阅后重新生成，再只读复验；不得提高像素容差掩盖缺陷 |

历史 `design-qa.md` 的旧主题和 v1.x 验收属于历史证据，不能作为当前 X-Pharma 新主题的通过证明。真实数据、生产 RUM、付费模型和商业部署仍分别验收，不能被前端风格检查代替。
