# X-Pharma 前端设计系统

## 目标与参考边界

用户于 2026-10-03 将全站方向调整为 OpenAI 式的简洁设计与交互，取代原 Claude 风格。研究和内部工作台共用纯白画布、浅灰导航、黑白主操作和无衬线层级；减少重复标题、装饰性状态和嵌套卡片，先呈现当前任务，再按需展开复杂条件。专业查询、密集表格、档案、证据及内部治理能力和权限边界保留，不将产品变成没有真实业务能力的聊天演示页。

参考边界为 [OpenAI 官方设计指南](https://openai.com/brand/) 与 [ChatGPT 公开产品入口](https://chatgpt.com/)；采用清晰层级和克制界面的方向，不复制商标或声称官方关系。当前网络下 ChatGPT 的浏览器参考页受访问验证阻断，没有绕过验证，也不宣称已完成登录后产品的逐像素比较。X-Pharma 的实际登录页已独立保存并审阅，产品验收仍须使用当前实现的真实浏览器截图与操作。

实现不复制参考产品的商标、图标、专有字体文件、源码或业务内容。X-Pharma 使用自己的名称和维护者提供的橙色品牌图像。所有标题和控件复用系统无衬线字体，标识和结构数据使用等宽字体；不依赖联网字体服务，缺少字体时按同一系统栈回退。相似的界面原则不等于整页像素一致。

## 品牌素材

产品和 GitHub 仓库名称统一为 **X-Pharma**（大小写固定）。Python 发行包规范化标识 `x-pharma`、内部模块和持久化标识不是对外软件名，不作破坏性迁移。

维护者于 2026-09-30 提供的透明 RGBA 原图保存在 `apps/web/brand/X-Pharma.png`，1254×1254，SHA-256 为 `1099f1a295921cc9e229995cd84aced5a2e1022e223bf6140f65d585f7b7d591`。不重绘、不裁切、不改色、不加背景；只通过锁定的 Pillow 生成等比缩放版本。两套工作台和登录页仅通过 `BrandMark` 使用同一个 128 px 图像，避免品牌入口分叉。

浏览器使用 16/32 px PNG、含 16/32/48/64 px 的 ICO 和 180 px Apple Touch 图标。三个 HTML 入口的声明由契约测试校验；Vite 产出带内容指纹的文件名，HTML 不缓存，从而在品牌更新后载入新图标。无需外部图片或字体服务。

默认 `/favicon.ico` 和可选 Swagger/ReDoc 文档同样使用这套构建产物，不另存第二份图标。默认图标地址强制重新验证，缺失、歧义或符号链接不提供任意文件；文档开关仍默认关闭，不因品牌调整开放 API 文档。

更新素材时替换原图、审查并更新生成器内的原图摘要，然后运行 `uv run python scripts/generate_brand_assets.py`；运行 `uv run python scripts/generate_brand_assets.py --check` 只读验证派生物。派生 PNG/ICO 不手工编辑。品牌图像按维护者提供的项目标识使用；Apache-2.0 不授予商标权。

## 唯一样式权威

- `styles/theme/tokens.css`：颜色、字体、字号、尺寸、圆角、阴影和状态语义。
- `styles/theme/foundation.css`：共享控件、导航、面板、表格、焦点和运动偏好。
- `styles/theme/typography.css`：密集信息与档案正文的可读性层级。
- `styles/theme/surfaces.css`：内部治理与专业业务表面的共享处理。
- `styles/theme/adapters.css`：结构编辑器、滚动容器及其他边界适配。
- `styles/*.css`：领域布局与响应式，不引入独立硬编码色值。
- `components/chartPalette.ts`：集中图表色盘；共享色值须与 CSS token 契约保持一致。

两个工作台通过同一 `mountApplication` 加载样式。禁止添加第二个主题开关、蓝色兼容链、页面级色盘或 `!important` 覆盖。新增视觉规则先复用既有 token；调整公共 token 时追踪全部消费组件。

## 核心规格

| 项目 | 规格 |
| --- | --- |
| 画布 / 导航 | `#ffffff` / `#f9f9f9` |
| 正文 / 强调正文 | `#333333` / `#0d0d0d` |
| 中性强调 / 可读强调文字 | `#5d5d5d` / `#303030`；橙色仅保留于原品牌图像 |
| 主操作 | 黑底白字；次操作白底细边框，普通业务面板不加阴影 |
| 控件 / 面板 | 10 px / 12 px 圆角；登录取消装饰性外框 |
| 字体 | 页标题、表单、导航、表格统一无衬线；等宽标识与结构数据 |
| 密度 | 主体 14 px、正文 13 px、元信息至少 12 px；不为装饰增加表格行高 |
| 焦点 | 高对比中性轮廓；键盘可见，不能只通过颜色表示状态 |

颜色语义包括成功、警告、错误和中性信息，不将所有状态涂成同一种强调色。表格列可横向滚动，但页面本身不得溢出；移动导航保持焦点管理和关闭恢复。动态加载、空、错误、无权限、禁用和恢复动作遵循同一体系。

注册复用登录页的白色画布、表单和账号入口导航；登录去除重复的英文/装饰眉题与锁形图标，账号入口、错误、成功、禁用和 OIDC 行为保留。邀请码管理仍复用企业表格、共享模态面板与唯一的模态焦点 hook；一次性邀请码关闭后清除，不引入另一套弹窗。

两套侧栏的账户区由 `WorkspaceAccountNavigation` 唯一拥有，组织、退出、加载/失败反馈和折叠控制集中于导航底部。内部人员的姓名不再配上无真实探针支撑的“在线”绿点。页面保留一个明确主标题，移除内部重复的英文眉题及其无消费者元数据/样式。

`SecondaryFilters` 只拥有渐进披露呈现，不读写查询、URL、缓存或权限。新闻的语言/会议/日期及流行病学的人群/口径/年龄/性别/日期默认收起，已有条件会显式展开并计数；控件关闭后仍保持挂载，草稿由原领域状态拥有。管线、临床、专利、交易和监管沿用各自已存在的高级条件与当前查询合同。清除、取消、保存、预览、档案返回、排序、分析和受控导出不被删除。

结构画板的操作与展开菜单使用各自独立的点击区域，移动工具栏换行而不遮住主操作；化学元素的标准颜色保留其科学语义。旧分组导航已没有消费者，相应 23 个样式选择器已删除，不保留另一套导航主题。

## 验证范围与通过标准

本次变更影响全局样式、图表和登录布局，不改业务 API 或权限协议。

| 风险 | 验证 | 通过标准 |
| --- | --- | --- |
| 全局主题分叉 / 颜色遗漏 | `DesignSystemContract.test.ts` | 两入口共用；领域无硬编码色盘；token 完整；文本对比度 AA |
| 业务交互、状态和导航退化 | 定向运行登录、工作台、品牌、设计合同、披露及受影响领域回归 | 当前变更及直接消费者通过；不手动运行无关全局测试 |
| 类型 / 格式 / 首屏膨胀 | `corepack pnpm check`、`corepack pnpm build` | 类型与格式无错误；原构建预算不放宽 |
| 页面、焦点、无障碍、重排 | 真实 Google Chrome / Playwright | 1440×900、1920×1080、1024×768、390×844；登录、全域导航、结果、弹窗及刷新正确；WCAG A/AA 与页面无溢出 |
| 有意视觉变化 | 原项目浏览器基线更新流程 | 人工审阅后重新生成，再只读复验；不得提高像素容差掩盖缺陷 |

历史 `design-qa.md` 的旧主题和 v1.x 验收属于历史证据，不能作为当前 X-Pharma 新主题的通过证明。真实数据、生产 RUM、付费模型和商业部署仍分别验收，不能被前端风格检查代替。

有意调整视觉时，可手动触发 `ci.yml` 的 `refresh_visual_baselines=true`。这只在显式手动运行时生成候选，随后必须执行原有只读浏览器验收；普通 push/PR 不会自动更新基线。候选 PNG 和摘要通过专用 artifact 导出，人工审阅后提交，再运行普通 CI。更新和复验使用同一受控真实运行时，不更改像素容差、性能预算或必需场景。
