# X-Pharma 项目交接

公开源码的唯一工作目录由实际 Git 克隆位置确定。E 盘开发环境使用
`/srv/wsl/projects/x-pharma`；Windows 可经 WSL 网络共享打开同一目录。

## 开源基线

本仓库从原开发工作树的完整当前源码建立，保留当时的未提交实现与已删除的过期生成模型。初次公开提交没有携带私有 Git 历史、运行数据、密钥或机器验收附件。原开发仓库、另一工作树、恢复数据和离线包留在原 E 盘位置，供本机对照和回滚。

公共产品名 X-Pharma，Python 发行包 `x-pharma`。内部 `pharma_intel`、CLI、迁移编号、来源与协议 schema、数据库与卷标识保持稳定；这次改名不要求重写已有业务数据。后续开发以公开仓库为源码权威，原恢复目录只作为既有运行与回滚资产。

## 模块与验证

架构见 [architecture.md](architecture.md)，模块职责与风险见 [codebase-guide.md](codebase-guide.md)。安装与验证命令以根 README 和 Makefile 为准；CI 保留后端、PostgreSQL、前端、双入口、部署及供应链门禁。发布流程与生产条件见 [release-evidence.md](release-evidence.md)。

每次改动说明影响范围与本次实际验证；历史测量不计为新提交的验证。生成客户端从 OpenAPI 生成，数据库迁移升级需通过真实数据库和 RLS 检查。

## 本机恢复边界

2026-09-30 的恢复交接确认原查询运行线与权威数据已恢复，真实查询、鉴权和对象引用有独立证据。该证据对应恢复时的原镜像，不能宣称为新 X-Pharma 代码的部署验收。

原自动来源目录尚未找齐，常驻 worker/scheduler 尚未启动；真实 LLM、可选 OCR 和商业生产门禁仍需验收。已有原文、规范数据和知识页继续由恢复运行线保管。开发和测试使用隔离配置、临时数据与独立端口。

源码、依赖、数据、缓存和证据均保留在 E 盘对应目录；机器私有配置和历史备份不进入 GitHub。
